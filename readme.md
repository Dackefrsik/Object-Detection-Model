Object Detection Model
Ett Python-projekt för objektdetektering med ett GUI-gränssnitt och dataset-hantering.

Installation
Installera de paket som krävs:

bash
pip install opencv-python pillow keyboard
Paket som behövs
opencv-python (cv2) - för kamerakontroll
pillow (PIL) - för bildhantering
keyboard - för tangentbordskontroller
Följande är redan inbyggda i Python:

tkinter - för GUI
os - för filhantering
shutil - för kopiering av filer
datetime - för tidsstämplar
Användning
Starta gränssnittet:

bash
python interface/interface.py
Dela upp datasetet:

bash
python trainModel/splitDataset.py
